# Samples

`drums/` holds the 16 drum samples Cut It plays, one per pad, and nothing else. A file's name
starts with its pad's number, two digits, `01` to `16`; anything after is free, so
`01 kick.wav` is pad 1. Pad 1 is bottom-left on the drum page, four a row upward, so 13 to 16
are the top row.

WAV, AIFF, MP3 or FLAC, any rate, mono or stereo. The deploy converts each to what Pd loads.

Not in git: this repo is public. Back them up some other way.
